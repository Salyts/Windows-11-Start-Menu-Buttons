Action Field — Format Reference
Action Formats
Prefix Example Description
path C:\Program Files\app.exe Opens a file or folder by absolute path
~ ~Downloads Opens a folder or file by name
cmd: cmd:control Runs via cmd.exe
shell: shell:shutdown /r /f /t 0 Runs via powershell.exe
press: press:Win+E Keyboard key press (Win32 VK codes)
web: web:https://windhawk.net/ Opens URL in default browser
ms-settings: ms-settings:bluetooth Opens a Windows Settings page
Modifier Signs (prepend to any action)
Sign Example Description
- -cmd:regedit Run as administrator
* *cmd:tasklist Show terminal window (cmd/shell only)
Signs can be combined: -*cmd:tasklist — run cmd in terminal as admin.
Multiple Commands
Use the + button to add multiple actions. They execute sequentially with a 50ms delay between them.
